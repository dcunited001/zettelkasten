*** Glue and Infinities

How does TeX distribute remaining white space across a layout line when it
encounters multiple distinct instances of glue?

TeX's glue system prioritizes infinite dimensions -- =fil=, =fill=, =filll=. Lower
order elements or finite stretch elements are completely ignored if a higher
order is present.

To scale a high-resolution PNG asset to exactly half the width of the text block
while cropping 20 points from its bottom margin, which syntax parameter profile
should be passed to =\graphicx=?

+ width=0.5\textwidth, viewport=0 20 {\the\width} {\the\height}, clip :: The

  - Enabling clip truncates the excess vector space.

*** Managing interactions between top-level document, configuration and classes

How should a custom class pass unhandled option configurations directly down to
an internal base class like =article.cls= safely?


+ \DeclareOption*{\PassOptionsToClass{\CurrentOption}{article}} :: The fallback
  option macro =\DeclareOption*= captures all unlisted options and relays them
  down to the target class via =\PassOptionsToClass= _before it loads_.

#+begin_quote
this one, i guess.. didn't know what a LaTeX "macro modifier" is.

"TeX doesn't natively allow the symbol =*= to be part of a macro's alphabetical
name, LaTeX commands check for this modifier using a conditional macro called
=\@ifstar=. If it detects a literal =*= character immediately following the command,
it shifts to execute a completely different sub-macro"

So this is another example of "find a decent character outside of a sub/set of
characters. String-escaping and free-monoids and whatnot. This is one primary
distinction between =LaTeX= and =TeX= then... okay.

Given the domain problems -- and the cost of "doing it wrong" for code shared
between documents -- actual macros (& argument handling/rebinding) would be
important to know about.
#+end_quote
