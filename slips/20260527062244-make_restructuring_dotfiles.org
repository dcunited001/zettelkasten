## Dotfiles organization

- I deploy by cloning the dotfiles to my laptop or desktop, where they remain in
  place. This is difficult to test. I update the sources with `git pull`.

- I prefer to avoid using NixOS home-manager because each deployment target has
  a few needs specific to its distribution.

- I'd like to migrate towards using `guix home`, though I will use this lightly.

- I could use GNU stow to link files, except many files link back to
  host-specific config files. Examples include a link from
  `~/.config/hypr/hypridle.conf` to
  `~/.dotfiles/config/hypr/myhost/hypridle.conf`. For `hyprland.conf` itself, I
  instead pass `Hyprland -c $HOME/.dotfiles/.config/hyprland.$(hostname).conf`
#+end_src
