** Plugin Marketplace

#+begin_example markdown
if you  know how to use android's `git-repo` tool, you can clone all the plugin sources using this:

```sh
d=omarchy-community
url=https://github.com/ectorepo/ectorepo
manifest=omarchy/default.xml
mkdir -p $d && cd $d
repo init -u "$url" -m "$manifest"
repo sync
```

The `repo sync` command will start failing soon (when repos change default branches or get deleted, unless I update... which I won't)

I'm not really providing it for public usage, but it is what it is. I used:

+ the [awesome.ecosyste.ms API](https://awesome.ecosyste.ms/) to get the themes from an awesom theme.
+ the omarchyplugins.com API (so these are all the verified repos)

There's also a ton of other lists of repos in ectorepo/ectorepo with some info on android `git-repo`. i mainly sync the repos for local copies to ripgrep or whatever... a bit antiquated though
#+end_example
