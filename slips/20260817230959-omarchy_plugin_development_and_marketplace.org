** Schema

*** Are schema's flat?

Technically, no. I've seen a =manifest.json= that includes two entrypoints

#+begin_src shell
checkouts=/data/ecto/omarchy/plugins

# most widgets as of mid-august have one schema
grep -rle 'schema"' -B20 --include="manifest.json" "$checkouts" \
    | sort | uniq -c | grep -vE '^ +1'
#+end_src

schema types. apparently these

#+begin_src shell
checkouts=/data/ecto/omarchy/plugins

# find $checkouts -name "manifest.json" -type f  -exec jq -r
# ff=$(fd 'manifest.json' $checkouts)

q='.. | (select(type=="object") | ."schema" // empty)
    | map(.type) | sort | join("\n")'
find "$checkouts" -name "manifest.json" -print0 \
    | parallel -0 "jq -r '$q'" | sort -u
#+end_src

There are about 4,000 files here, though they end up being paged in memory (i
think)... (i thought =jq= was python, but i guess that's yq/xq)

|      | above     | below    |
|------+-----------+----------|
| real | 0m11.343s | 0m5.023s |
| user | 0m15.646s | 0m5.359s |
| sys  | 0m21.220s | 0m8.672s |

=cat= is cheap (it's probably still got the sticky bit). Above, many =jq= are
started. Below, there's only one memory image loaded (that contains all the
state change inside a single process)

I think jq's =..= is slow here

if rg -n 'QtWebEngine|WebEngineView|WebView|playerctl|node_modules' \
    --glob '*.qml' --glob '*.js' --glob '*.sh' --glob '*.service' \

** Plugin Marketplace

#+begin_example markdown
if you  know how to use android's `git-repo` tool, you can clone all the plugin sources using this:

```sh
d=omarchy-community
url=https://github.com/ectorepo/ectorepo
manifest=omarchy/default.xml
mkdir -p $d && cd $d
repo init -u "$url" -m "$manifest"
repo sync
```

The `repo sync` command will start failing soon (when repos change default branches or get deleted, unless I update... which I won't)

I'm not really providing it for public usage, but it is what it is. I used:

+ the [awesome.ecosyste.ms API](https://awesome.ecosyste.ms/) to get the themes from an awesom theme.
+ the omarchyplugins.com API (so these are all the verified repos)

There's also a ton of other lists of repos in ectorepo/ectorepo with some info on android `git-repo`. i mainly sync the repos for local copies to ripgrep or whatever... a bit antiquated though
#+end_example
