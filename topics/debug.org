*** debuginfod

Retroactively retrieve debug symbols for a standard binary from an online
service where they're available. Requires:

+ waiting 52 hours for debuggable browsers to compile
+ determining source map/unmap to re-merge symbols
+ stripping debug symbols (with whatever's required for them to be re-merged in)
+ maintaining registry of lazily debuggable symbols
+ someone actually fetching these

Something like a =source-map= and =source-unmap=. their inverse maps would be
composed, in reverse, later: $(s_{unmap})^{-1} \circ(s_{map})^{-1}$

It like each =ELF= could have a =DWARF=... oh so that's what that is.
