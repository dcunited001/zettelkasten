** AMPL

Found an [[https://flathub.org/en/apps/com.ampl.ide][AMPL IDE]] on flathub

+ [[https://en.wikipedia.org/wiki/AMPL][AMPL Wiki]]. See list of problem types. Supports [[https://en.wikipedia.org/wiki/Constraint_programming][Constraint programming]]
+ MP Library and [[https://mp.ampl.com/features-guide.html#support-by-solvers][feature matrix for solvers]]

Python can control AMPL with [[https://ampl.com/products/ampl/integrations/python][amplpy]].
